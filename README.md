# agent-test

## Overview

`agent-test` is a sandbox repository owned by **RajiSh21** used for testing and experimenting with GitHub Copilot's coding agent capabilities.

## Purpose

This repository serves as a playground for:

- Testing how GitHub Copilot agents interpret and respond to natural-language problem statements
- Experimenting with automated code generation, refactoring, and documentation tasks
- Validating agent-driven workflows such as pull request creation, issue resolution, and code review

## Current State

The repository is currently minimal by design. It exists primarily to provide a safe, isolated environment where agent tasks can be triggered and observed without affecting production code.
